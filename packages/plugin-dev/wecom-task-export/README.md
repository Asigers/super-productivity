# 企业微信任务同步（个人插件）

将两个选定项目的未归档主任务单向导出到一个企业微信智能表格。字段 ID 是为当前工作表固定配置的；其他表需要修改 `plugin.js` 中的字段 ID 和项目选项。仅在一台 Windows 桌面客户端上启用。

## 安装和配置

打包 `manifest.json`、`plugin.js` 和 `index.html` 到 ZIP 的根目录，在设置 → 插件中上传。启用插件，在插件设置中配置企业微信「接收外部数据」Webhook，选择两个项目后保存。预览任务数量，确认后启动同步。首次启动会上传符合条件的已有任务（包括任务备注）。应用运行时会检测变更并重试，重启后再次对账。应用关闭时不运行。

可选：在智能表格中添加「优先级」单选列，选项为「高」「中」「低」「未设置」，从「接收外部数据」示例中复制该字段 ID 到插件设置。保存并重新启动同步后，已有记录也会更新；留空则不写入优先级列。未设置优先级时写入「未设置」选项。当前客户端任务对象包含该字段，但公开插件 API 类型暂未声明它，后续版本需重新验证兼容性。

Webhook 保存在插件的本机 secret 存储中，不同步或导出，但未加密存储。项目选择、任务 ID、企业微信 record_id、字段哈希及待核对状态保存在客户端的 localStorage 中，也不随应用同步或备份。不要清除、丢失这些映射，否则可能重复创建；迁移设备或更换表格需先人工处理映射。已有映射时插件禁止直接更换 Webhook，包括更换 key。

## 限制与恢复

- 子任务和归档任务不上传；任务被删除、归档或移出项目后，原表格行保留不变。插件不会读取企业微信的修改。
- 计划日期被移除时，由于企业微信 Webhook 文档未明确清空日期的格式，插件不会清空原单元格；请根据设置界面的提示手动清空。日期写入及清空前应在测试表验证。
- 如果新增失败或响应丢失，插件无法确定表格是否已经创建记录，会停止同步并显示任务 ID。按任务 ID 核查：如果已经存在，获取该行的 record_id 并在插件设置中绑定；只有确认不存在时，才能手动允许重新新增。企业微信文档提供查询 API 或智能表格 AI 字段获取 record_id。
- 同步读取本机当前数据；多台设备并发写表、清除插件存储、卸载重装或数据恢复均可能需要人工核对。不要在多个客户端启用同一表格的同步。
- 请先使用测试表验证当前 Windows 客户端能否访问 Webhook，以及列类型、日期、返回的 record_id；不要把真实 Webhook 发到聊天或提交到仓库。
